## Key Learnings
- A Osiany quer evidência científica real nas decisões visuais, não gosto pessoal. Citar fontes e dar o nível de evidência.
- Ela escolhe pela própria percepção mesmo contra a recomendação (escolheu Petróleo). Apresentar sempre uma prévia visual das opções antes de pedir decisão.
- O Instagram bloqueia leitura automatizada de perfis: a auditoria de 30 perfis ficou pendente e é manual (protocolo no step-04 §6).
- O Playwright pode estar ocupado por outra sessão. Para revisar HTML, usar o Chrome headless (a janela mínima é 500 px; para testar mobile, usar iframe de 390 px).
