# Marcas salvas

Cada marca usada na squad ganha uma pasta aqui, criada pelo Fred na primeira execução:

```
marcas/<marca>/ficha.json   ← cores (fundo principal, destaque, terceira cor), fontes, logos, legenda, glossário
marcas/<marca>/perfil.md    ← respostas do formulário A + o que foi aprendido (referências, o que não repetir)
```

Nas próximas execuções o Fred só pergunta "para qual marca?" e o formulário do vídeo.
Para corrigir algo da marca, edite estes arquivos ou peça ao Fred — a correção vale para os próximos vídeos.
