# Vídeos do Ecossistema EXPX

Todo vídeo deve partir de uma transformação empresarial ou técnica relevante para
software houses.

## Enquadramento por canal

### Thulio Bittencourt

Explique:

- O que está mudando.
- Por que isso importa.
- Qual percepção está errada.
- Que decisão o empresário precisa tomar.

### EXPX

Explique:

- Qual problema existe.
- Como diagnosticar.
- Qual processo precisa mudar.
- Como implementar.
- Qual indicador acompanhar.

### Academia do Código

Mostre:

- O que será construído.
- Qual problema resolve.
- Como funciona.
- Como implementar.
- Quais limitações existem.
- Como gera valor para a empresa ou para o cliente.

## Estrutura de roteiro

Adapte ao formato:

1. Gancho baseado em consequência.
2. Promessa do vídeo.
3. Contexto.
4. Problema.
5. Diagnóstico.
6. Tese ou solução.
7. Demonstração, exemplo ou aplicação.
8. Implicação empresarial.
9. Próximo passo.

## Títulos

Prefira títulos baseados em resultado ou tensão.

Evite:

“Conheça cinco ferramentas de IA.”

Prefira:

“Cinco aplicações de IA que podem aumentar a margem de uma software house.”

Evite:

“Criando um agente com n8n.”

Prefira:

“Criando um agente que reduz o trabalho manual da implantação.”

## Thumbnails

A thumbnail deve complementar o título, não repeti-lo.

Use uma ideia visual simples, uma tensão e poucas palavras.

Não use números, resultados ou promessas que não possam ser sustentados.

## Série principal

Para conteúdos autorais do Thulio, considere a série:

**IA que Vira Receita**

O vídeo deve aproximar o público do Diagnóstico do DNA, Workshop Arquitetura de
Receita, Software House 10X ou Sala dos Mestres, conforme seu estágio.
