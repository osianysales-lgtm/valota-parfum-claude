## Instruções
Analise o perfil do cliente e, seguindo as regras do manual de prospecção ativa,oriente o vendedor sobre os próximos passos a serem tomados. Considere as seguintes diretrizes:

- Identifique o estágio atual do cliente no funil de vendas.
- Sugira ações específicas para avançar o cliente para a próxima etapa do funil.
- Indique os recursos ou materiais de apoio que podem ser úteis para o vendedor.
- Forneça recomendações sobre como abordar o cliente, considerando suas necessidades e interesses.
- Estabeleça prazos para as próximas ações e defina responsáveis para cada tarefa.
