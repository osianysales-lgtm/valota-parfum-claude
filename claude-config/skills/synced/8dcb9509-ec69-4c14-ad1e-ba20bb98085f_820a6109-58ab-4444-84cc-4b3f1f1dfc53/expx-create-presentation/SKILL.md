# Apresentações do Ecossistema EXPX

Crie uma narrativa visual com começo, desenvolvimento e conclusão.

Não transforme um documento em slides dividindo parágrafos.

## Enquadramento

Determine:

- Quem apresenta.
- Para quem.
- Objetivo.
- Área do DNA.
- Decisão esperada.
- Tempo disponível.
- Produto ou próximo passo.

## Narrativa

A apresentação deve possuir:

1. Uma abertura que revele tensão, mudança ou problema.
2. Um diagnóstico que reorganize a percepção.
3. Uma tese clara.
4. Um modelo ou caminho.
5. Exemplos aplicados a software houses.
6. Uma decisão ou ação final.

## Construção dos slides

Cada slide deve possuir uma função clara.

Use:

- Títulos que expressem conclusões.
- Uma ideia principal por slide.
- Pouco texto quando a apresentação for falada.
- Diagramas para relações.
- Tabelas para comparações.
- Indicadores quando houver dados reais.
- Exemplos concretos.
- Direção visual coerente com a marca.

Evite:

- Títulos genéricos.
- Paredes de texto.
- Slides decorativos sem função.
- Excesso de conceitos em um único slide.
- Imagens genéricas de robôs ou cérebros.
- Dados sem fonte.
- Repetição literal de “IA que vira receita” em todos os slides.

## Voz das marcas

### Thulio

Apresentações mais autorais, provocadoras e orientadas ao futuro.

### EXPX

Apresentações executivas, diagnósticas e orientadas à implementação.

### Academia do Código

Apresentações técnicas, didáticas e demonstráveis.

### Sala dos Mestres

Apresentações de decisão, acompanhamento e execução.

## Entrega

Quando o usuário não definir outro formato, apresente para cada slide:

- Número.
- Título.
- Conteúdo essencial.
- Sugestão visual, somente quando útil.
- Nota do apresentador, quando necessária.

O último slide deve conduzir a uma decisão, compromisso ou próximo passo coerente.
